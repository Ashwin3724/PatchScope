# PatchScope — Visual Anomaly Lab

Preview image is included in encoded form; run `python restore_assets.py` to restore `docs/screenshot.png` locally.
A local, hands-on **classical computer-vision baseline** for finding unusual image patches relative to a reference set of synthetic normal surfaces. The generated samples, labels and heatmaps are educational; this is **not PatchCore, not a pretrained neural network, and not a production defect detector**. No real factory data are included. Never use results to accept, reject or assess safety of real products.

## Start on Windows

Install Python 3.11–3.13 and add it to PATH. Extract the ZIP. In the `PatchScope` folder, click the File Explorer address bar, type `cmd` and press Enter. Run:

```cmd
python run.py
```

If `python` is unavailable, try `py run.py`. First run creates `.venv` and installs dependencies; internet is needed for installation. Wait for the browser, or open http://127.0.0.1:8020/. Keep the terminal open; press Ctrl+C to stop. After installation, the app and generated data run offline without an API key or GPU. On macOS/Linux use `python3 run.py`. Port conflict? Windows: `set PORT=8021` then `python run.py`.

## Use it

Click **Try synthetic defect** or **Try normal sample**, or upload a PNG/JPEG (max 2 MB, 4 million pixels, at least 16×16). The app resizes every input to 128×128 and processes it locally. The server can use temporary files for uploads; don't upload sensitive images. A score at or above the cutoff is flagged. Heatmap red intensity is normalized to each image, so red is not a probability or a fixed comparable scale. The system has not been validated on real images.

## Actual algorithm

- Generate 32 fictional normal training images with fixed seeds. Each 128×128 grayscale image yields 64 non-overlapping 16×16 patches.
- For each patch, calculate four handcrafted features: mean intensity, intensity standard deviation and average absolute differences vertically and horizontally. Fit `StandardScaler` and a brute-force nearest-neighbor reference on training patches only.
- Use 12 separate synthetic normal validation images and the 95th percentile of their **maximum patch scores** as the image cutoff. This small sample does not guarantee a 5% false-alarm rate.
- Score a patch by Euclidean distance in standardized feature space to its nearest training patch. The image score is the maximum of its patch distances. An image-normalized red overlay highlights relatively high-scoring tiles. This is a coarse 8×8 tile overlay, not a pixel-level segmentation model.
- Evaluate once in the code on 8 synthetic normal and 8 synthetic defective test images (different generator seeds). The UI reports image-level ROC AUC and the numbers flagged at the validation cutoff. These images are simple and generated by the same algorithm; test results were inspected during development, so they do not demonstrate real-world accuracy.

The generated dark rectangular defect is deliberately simple and can produce deceptively good AUC. Do not put these synthetic numbers on your CV as industrial performance. A proper project extension would compare methods on representative, appropriately licensed factory data, measure image and pixel metrics, examine different lighting and defect types, and use a genuinely independent test set. [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) is one research starting point; check its data license and usage terms. This ZIP does not contain that dataset.

## Code and tests

- `app/vision.py`: generated surfaces, image validation, features, reference bank, cutoff, overlay.
- `app/main.py`: FastAPI upload and sample endpoints; local-only checks are in `app/base.py`.
- `app/static/`: browser interface. `GET /docs` serves API documentation.
- `tests/test_project.py`: automated unit and API tests. `docs/AUDIT.md` and `docs/INTERVIEW_STUDY_GUIDE.txt`: audit and beginner guide.

Windows test commands after running the app once:

```cmd
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
```

macOS/Linux: replace `.venv\Scripts\python.exe` with `.venv/bin/python`. Tested in a Linux development environment; Windows has not been independently verified. A test pass verifies selected behavior, not real detection quality.

## Boundaries and responsible use

Resizing, simple grayscale texture features, material changes, lighting and camera angle can generate false alarms or conceal defects. It cannot fit a user-provided reference bank; uploads are compared with generated normal surfaces only. No neural feature extractor, OCR, camera integration, production monitoring, authentication, or multi-user support is present. The server binds to localhost; do not expose it on a network.
